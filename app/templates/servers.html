    Настроить YouTube

    Эти данные сохраняются на relay-сервере. В Moblin их вводить не нужно — приложение отправляет видео только на SRT-адрес сервера.

    Если ретранслятор активен, сначала завершите broadcast в YouTube и остановите relay.

    !

    Очистить настройки YouTube?

    URL и stream key будут удалены с relay-сервера. После этого relay не запустится, пока YouTube не будет настроен заново. Relay должен быть остановлен.

    Входящий поток

    SRT-адрес для Moblin

    В Moblin откройте: Settings → Streams → профиль → URL. Вставьте только SRT URL. Если Moblin предложит заменить его прямым YouTube RTMP URL, нажмите No.

    Для комментариев отдельно укажите Video ID текущего broadcast: Settings → Streams → профиль → Streaming platforms → YouTube → Manage streams / Video IDs. Video ID и stream key — разные данные; RTMPS URL и stream key в Moblin не вводятся.

    Адрес содержит секрет доступа, поэтому требуется повторное подтверждение.

    Не отправляйте эти адреса посторонним: в них находится пароль входящего SRT-потока.
