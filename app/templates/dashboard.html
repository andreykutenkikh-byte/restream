Управление серверами

Шаг 1

Ключ потока YouTube

Скопируйте stream key из YouTube Live Control Room. Он сохраняется только на HK relay.

Дополнительно: заменить RTMPS-адрес

Обычно адрес не меняется. Используйте точное значение из YouTube Studio.

Если relay активен, сначала завершите broadcast в YouTube и остановите relay.

Шаг 2

Ссылка для Moblin или OBS

Moblin: Settings → Streams → профиль → SRT(LA) → Implementation / Реализация → Official. Установите Latency: 2000 ms и Big packets: ON. SRT URL скопируйте целиком в поле URL и не редактируйте.

Дополнительно

Для комментариев в Moblin отдельно укажите Video ID текущего broadcast. Video ID и stream key — разные данные.

Если Moblin предложит заменить SRT URL прямым YouTube RTMP URL, нажмите No.
!

Удалить данные YouTube?

Relay не запустится, пока RTMPS URL и stream key не будут настроены заново.
